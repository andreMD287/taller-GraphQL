# GraphQL Workshop — Sistemas Distribuidos

Taller práctico e interactivo sobre GraphQL aplicado a Sistemas Distribuidos.

---

## 🚀 Objetivo

El objetivo de este proyecto es demostrar, de forma práctica, cómo funciona GraphQL y por qué es útil en arquitecturas distribuidas modernas.

Durante la demostración se exploran:

- Queries
- Mutations
- Subscriptions
- Introspection
- GraphQL como API Gateway
- Comunicación en tiempo real con WebSocket

---

## 🛠️ Tecnologías utilizadas

- GraphQL
- Apollo Server
- Node.js
- HTML / CSS / JavaScript
- WebSocket

---

## 📦 Instalación

Instalar dependencias:

```bash
npm install
````

## ▶️ Ejecutar el proyecto

## 🎯 Contenido del taller

El taller incluye ejercicios prácticos sobre:

### ✅ Queries

## 💡 Idea principal

GraphQL permite que el cliente solicite exactamente los datos que necesita utilizando un único endpoint.

Esto ayuda a:

* reducir tráfico innecesario,
* evitar over-fetching y under-fetching,
* unificar múltiples microservicios,
* simplificar arquitecturas distribuidas.
